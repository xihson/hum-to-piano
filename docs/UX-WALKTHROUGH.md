# UX 走查：v2（`/v2/`）

逐屏、逐控件说明 v2 原型的界面和交互。每一项都写了：它在 Figma 里是哪一帧、在 `v2/index.html` 里的 DOM id、在 `v2/js/app.js` 里由哪个函数处理。

改界面前先读 [DESIGN.md](DESIGN.md) 的文案规则。改交互前先读 [DECISIONS.md](DECISIONS.md)，很多看起来"可以顺手改"的地方，都是用户明确定过的。

---

## 0. 总体流程

```
首页（麦克风）──录音──▶ 录音中 ──停止──▶ 分析 ──▶ 作品页（只有录到的轨道）
   │                                               │
   └──上传录音文件 ─────────────▶ 分析 ─────────────┘
                                                    │ 点"编曲"
                                                    ▼
                                       作品页（加上和弦、贝斯、鼓）
                                                    │ "重新录" → "从头开始"
                                                    ▼
                                                  首页
```

三个屏幕是 `index.html` 里的三个 `<section>`：`#home`、`#recording`、`#work`。由 `show(id)` 切换，同一时间只显示一个。

## 1. 首页（Figma 13 / 13b）

| 元素 | DOM | 行为 | 代码 |
|---|---|---|---|
| 左上角 logo | `[data-logo]` ← `#logoTpl` | 三行：说话的人 → 钢琴、拍手 → 鼓、响指 → 踩镲。输入图标在左，输出图标在右。**只在首页和录音页显示**，作品页没有。顶部留白 29px。 | 页面加载时从模板复制 |

| 上传 | `#uploadBtn` → `#fileInput` | 选音频或视频文件，走"不开节拍器"的分析流程。 | `#fileInput` 的 change 处理 |

三个圆形按钮的间距是 **9px**，这是用户在 Figma 里亲手改的，不要动。

## 2. 录音中（Figma 22a–25）

麦克风**只识别哼唱**。鼓点靠手动：电脑上按键，手机上按两个大按钮。

| 元素 | DOM | 行为 | 代码 |
|---|---|---|---|
| 大字 | `#bigNote` | 显示当前音名（如 A4），没有声音时变淡。 | `liveLoop()` |
| 节拍点 | `#beatDots` | 只在开节拍器时显示，8 个点（两小节），当前拍点亮。 | `liveLoop()` |
| 实时画面 | `#live` / `#liveCv` | **"现在"那根竖线固定在正中间**，过去的内容往左滚，右半边留空。上方是音高线（蓝），下方两行是军鼓（大黄点）和踩镲（小黄点），每按一下就在“现在”线上落一个点。**不加文字标注**（用户要求）。开节拍器时画拍线和小节线，不开时每秒一条淡线。 | `drawLive()` |
| 停止 | `#stopBtn` | 停止并分析。回车键效果相同。分析时全屏转圈 `#analyzing`。 | `stopMain()` → `stopCapture()` → `analyzeTake()` → `newSong()` |
| 计时 | `#timer` | 从第 0 拍开始计（不含预备拍）。 | `liveLoop()` |
| 放弃确认 | `#quitModal` | 按 Esc 弹出“放弃这次录音？”：“继续录音”关掉弹窗，红色“放弃 Esc”回首页。**再按一次 Esc = 放弃**。弹窗打开时录音不停，空格、Alt、回车暂时不响应。 | `openQuit()`、`abandonMain()` |

**按键**（只在录音页、或添加段落弹窗正在录音时生效；预备拍期间按的鼓键忽略）：

| 键 | 作用 |
|---|---|
| 空格 | 军鼓：立刻发声，在“现在”线上落一个大黄点 |
| Alt（左右都行；Mac 上是 Option） | 踩镲：同上，小黄点 |
| 回车 | 停止并分析 |
| Esc | 录音页：先弹确认，再按一次放弃并回首页；添加段落弹窗：直接关掉弹窗，丢掉这段录音（不确认） |

焦点在按钮上时，空格和回车也不会点到按钮（keydown 和 keyup 都 `preventDefault`）。

**开节拍器时**：节拍器声音是 1250/1600 Hz 的短正弦音，高于音高识别的上限 800 Hz。录音里如果收到了节拍器的声音，会用它来校准人声的时间（`goertzelPeak`）。按键的时间另算，见 ARCHITECTURE 的“按键时间换算”。

**识别失败**（没听出旋律，也没有按过鼓键）：提示“没有听出旋律。离麦克风近一点再试。”，然后回到首页。只按了鼓键、没有哼唱，也会生成作品（只有军鼓 / 踩镲轨道）。

### 3.2 工具栏

| 元素 | DOM | 行为 |
|---|---|---|
| 播放 / 暂停 | `#playBtn` | 从播放头位置开始播。空格键效果相同。`startPlay()` / `stopPlay()` |

| 调 | `#keyChip` | 弹出 24 个调。改调后如果已编曲，会重新配所有和弦（`Arrange.reharmonize`），进入撤回历史。 |

### 3.3 编排区 `#arr`

左边是轨道名列 `#arrLabels`（宽 150px，手机上 112px），右边是可横向滚动的时间线 `#arrScroll > #arrTl`。由 `renderArr(anim)` 每次整体重画。

**轨道**（`lanes()` 决定显示哪些，**没有内容的轨道不显示**）：

| 轨道 | 出现条件 | 颜色变量 | 可做的事 |
|---|---|---|---|
| 旋律（按乐器各一条：钢琴、弦乐……） | 某段有该乐器的旋律 | `--i-<乐器>` | 名称旁的 ▾ 换整条轨道的乐器；点片段选中 → 钢琴卷帘 |
| 拍手 | 有拍手 | `--hits` | 点片段 → 鼓点格子 |
| 响指 | 有响指 | `--hits` | 同上 |
| 和弦 | 已编曲 | `--chords` | 拖动互换、点击 → 和弦选择 |
| 贝斯 | 已编曲 | `--bass` | 只读，由和弦和风格生成 |
| 鼓 | 已编曲且风格有鼓（纯钢琴没有） | `--kit` | 只读 |

每条轨道右边的喇叭图标是静音开关（存在 `song.mute`），只影响播放和 WAV 导出，MIDI 总是导出全部轨道。

**段落条**（时间线顶部，`.sec`）：显示段落名和拖动手柄。

- **点击**：选中整段，下方编辑区显示该段的旋律（没有旋律就显示鼓点格子，再没有就显示和弦）。
- **拖动**：换段落顺序，所有轨道一起移动。拖动时有蓝色竖线标出插入位置。

**和弦块**（`.chord`）：

- **点击**：选中并试听，编辑区切到和弦选择。
- **拖到另一个和弦块上**：两个小节的和弦互换，可以跨段落。拖动时原位置显示虚线框，目标块加黑框。

**空白处单击**：把播放头移到该拍，取消选中。

**"＋段落"**（`.add-sec`）：紧跟在最后一段后面，点开添加段落弹窗（见 3.5）。未编曲时也能用。

### 3.4 编辑区

未选中任何东西时显示一行小字"选中段落来编辑"（`#editorHint`）。选中后换成编辑卡片 `#editor`，由 `renderEditor()` 根据 `sel.type` 决定显示哪种：

| 选中 | 标题 | 内容 | 代码 |
|---|---|---|---|
| 旋律片段 / 段落 | 旋律 · 主歌 + 乐器 ▾（只改这一段） | 钢琴卷帘 | `buildPianoRoll()`、`prDown()`、`drawPR()` |
| 拍手 / 响指片段 | 节奏 · 主歌 | 两行 16 分音符格子（拍手、响指），点一下加或删一个鼓点 | `buildHitGrid()` |
| 和弦块 | 和弦 · 主歌 第 3 小节 | 第一排：调内 7 个和弦（标级数）；第二排：七和弦、挂留和弦、借用和弦 | `buildChordPicker()`、`setChord()` |

**钢琴卷帘的操作**：

- 拖音符本体：同时改音高和位置（对齐到 16 分音符），拖动时出现提示"G4 → A4"，换音高时会试听。
- 拖音符右边缘 8px 内：改长短。
- 双击空白：在该处加一个 1 拍长的音。
- 选中音符后按 Delete 或 Backspace：删除。

**编辑区右上角工具**：复制（在后面插入这段的副本，**副本是独立的**）、删除（按选中类型：段落 → 删整段，至少保留一段；旋律 → 清空旋律；节奏 → 清空鼓点；和弦选中时不显示删除）、关闭。**这里不放撤回和重做按钮**（用户决定，见 DECISIONS）。

### 3.5 添加段落弹窗 `#addModal`（Figma 12，已按单按钮录音简化）

- **段落**：主歌、副歌、桥段、尾声。
- **乐器**：6 种。
- **录音区**：与录音页同样的画面，只是更小。录音时**固定开节拍器**，速度用歌曲当前速度，先打 4 下预备拍。
- **伴奏开关**：编过曲时，录音期间循环播放第一段的和弦、贝斯和底鼓。故意不放军鼓和踩镲，否则扬声器的声音会被当成拍手。
- **添加**：录完才能点。新段落插在"尾声"之前（没有尾声就放最后）。已编曲时会自动配和弦。添加后自动选中新段落。

**和 Figma 12 的差别**：去掉了"方式（哼唱 / 拍手）"这一行，因为一个按钮同时识别。

### 3.6 Suno 弹窗 `#sunoModal`（Figma 6）

三步：

1. **音频**：选"原声哼唱"或"我们的编曲"，然后下载。
2. **风格提示词**：由 `Arrange.sunoPrompt()` 根据风格、乐器、速度、调生成英文提示词，旁边有复制按钮。
3. **打开 Suno**：链接到 `suno.com/create`。

Suno 没有公开 API，所以只能这样手动交接（见 DECISIONS）。

### 3.7 "编曲"过渡动画（Figma 17 → 18 → 19，说明卡在 18 下方）

点"编曲"后（`#arrangeBtn` 处理 → `commit(..., 'arrange')` → `renderArr('arrange')`）：

1. 按钮变成转圈加"编曲中"，持续约 1.7 秒，然后换成风格切换条。
2. 新段落（前奏、复制的主歌、尾声）从中间展开（`.sec.enter`），复制段的片段淡入（`.clip.enter`）。
3. 和弦、贝斯、鼓三条轨道依次滑入，每条间隔 120ms（`.lane-enter`，用 `--i` 控制先后）。
4. 一块盖住新轨道的白色遮罩从左往右揭开，前面有一条带光晕的蓝色扫描线（`.wipe` + `.sweep`，1.2 秒，延迟 0.45 秒开始）。

切换风格时（`renderArr('style')`）只做第 4 步，没有延迟。系统设置了"减少动态效果"时，所有动画都关闭。

## 4. 键盘

| 键 | 作用 |
|---|---|
| 空格 | 首页：开始录音；录音页：军鼓（见第 2 节）；作品页：播放 / 暂停（焦点在按钮或输入框上时不触发） |
| Alt | 录音页：踩镲 |
| 回车 | 录音页：停止并分析 |
| Ctrl/⌘ + Z | 撤回 |
| Ctrl/⌘ + Shift + Z，Ctrl/⌘ + Y | 重做 |
| Delete / Backspace | 删除钢琴卷帘里选中的音符 |
| Esc | 录音页：放弃确认（两下）；其他：依次关菜单 → 关弹窗 → 取消选中 |
