# UX 走查：v2（`/v2/`）

逐屏、逐控件说明 v2 原型的界面和交互。每一项都写了：它在 Figma 里是哪一帧、在 `v2/index.html` 里的 DOM id、在 `v2/js/app.js` 里由哪个函数处理。

改界面前先读 [DESIGN.md](DESIGN.md) 的文案规则。改交互前先读 [DECISIONS.md](DECISIONS.md)，很多看起来"可以顺手改"的地方，都是用户明确定过的。

---

## 0. 总体流程

```
首页（麦克风）──录音──▶ 录音中 ──停止──▶ 分析 ──▶ 作品页（只有录到的轨道）
   │                                               │
   └──上传录音文件 ─────────────▶ 分析 ─────────────┘
                                                    │ 点"编曲"
                                                    ▼
                                       作品页（加上和弦、贝斯、鼓）
                                                    │ "重新录" → "从头开始"
                                                    ▼
                                                  首页
```

三个屏幕是 `index.html` 里的三个 `<section>`：`#home`、`#recording`、`#work`。由 `show(id)` 切换，同一时间只显示一个。

## 2. 录音中（Figma 22a–25）

麦克风**只识别哼唱**。鼓点靠手动：电脑上按键，手机上按两个大按钮。

| 元素 | DOM | 行为 | 代码 |
|---|---|---|---|
| 预备拍 | `#countIn` | 见下面“预备拍”。 | `placeCount()`、`countIn()` |
| 大字 | `#bigNote` | 显示当前音名（如 A4），没有声音时变淡。 | `liveLoop()` |
| 节拍点 | `#beatDots` | 只在开节拍器时显示，8 个点（两小节），当前拍点亮。 | `liveLoop()` |
| 实时画面 | `#live` / `#liveCv` | **"现在"那根竖线固定在正中间**，过去的内容往左滚，右半边留空。上方是音高线（蓝），下方两行是军鼓（大黄点）和踩镲（小黄点），每按一下就在“现在”线上落一个点。**不加文字标注**（用户要求）。开节拍器时画拍线和小节线，不开时每秒一条淡线。 | `drawLive()` |
| 停止 | `#stopBtn` | 停止并分析。回车键效果相同。分析时全屏转圈 `#analyzing`。 | `stopMain()` → `stopCapture()` → `analyzeTake()` → `newSong()` |
| 计时 | `#timer` | 从第 0 拍开始计（不含预备拍）。手机上在停止按钮下面。 | `liveLoop()` |
| 军鼓、踩镲大按钮 | `#recPads .pad` | **只在手机上**（Figma 25）：实时画面下面左右两个，按下（`pointerdown`）就打一下，按下态保持约 120ms。电脑上不放按钮，看 logo 用按键。 | `.pad` 的 pointerdown 处理 |
| 放弃确认 | `#quitModal` | 按 Esc 弹出“放弃这次录音？”：“继续录音”关掉弹窗，红色“放弃 Esc”回首页。**再按一次 Esc = 放弃**。弹窗打开时录音不停，空格、Alt、回车暂时不响应。 | `openQuit()`、`abandonMain()` |

**预备拍**（Figma 22a、22b、23a、23b）：

1. **阶段 1，全屏只有计数**：录音页其他内容 `opacity: 0`（占位不变）。开节拍器时是 8 个大圆点（两小节，第 1、5 个大一点，4 个一组），随节拍依次点亮，节拍器第 1、5 拍重音；不开节拍器时是蓝色大数字 3、2、1，每秒一个，没有声音。
2. **阶段 2，缩回上方**：开节拍器在第一小节结束时，不开节拍器在第 2.5 秒。计数用 FLIP 动画（400ms）缩小飞到 `#beatDots` 或 `#bigNote` 的位置，其余内容再淡入（300ms）。
3. **阶段 3，开始录**：预备结束时实时画面才开始滚动，计时从 0:00 开始。开节拍器时这时音名才出现，节拍点平移让位。

实现：`#countIn` 里放一份目标元素的副本，阶段 1 每帧按目标的位置放好再放大到屏幕中间；到点后把 transform 过渡回 `none`。`prefers-reduced-motion` 时直接切换。添加段落弹窗里不做全屏，见 3.5。

**按键**（只在录音页、或添加段落弹窗正在录音时生效；预备拍期间按的鼓键忽略）：


| 键 | 作用 |
|---|---|
| 空格 | 军鼓：立刻发声，在“现在”线上落一个大黄点 |
| Alt（左右都行；Mac 上是 Option） | 踩镲：同上，小黄点 |
| 回车 | 停止并分析 |
| Esc | 录音页：先弹确认，再按一次放弃并回首页；添加段落弹窗：直接关掉弹窗，丢掉这段录音（不确认） |

焦点在按钮上时，空格和回车也不会点到按钮（keydown 和 keyup 都 `preventDefault`）。

**开节拍器时**：节拍器声音是 1250/1600 Hz 的短正弦音，高于音高识别的上限 800 Hz。录音里如果收到了节拍器的声音，会用它来校准人声的时间（`goertzelPeak`）。按键的时间另算，见 ARCHITECTURE 的“按键时间换算”。

**识别失败**（没听出旋律，也没有按过鼓键）：提示“没有听出旋律。离麦克风近一点再试。”，然后回到首页。只按了鼓键、没有哼唱，也会生成作品（只有军鼓 / 踩镲轨道）。

### 3.3 编排区 `#arr`

左边是轨道名列 `#arrLabels`（宽 150px，手机上 112px），右边是可横向滚动的时间线 `#arrScroll > #arrTl`。由 `renderArr(anim)` 每次整体重画（重画前后保住 `scrollLeft`）。

**横向滚动**（Figma 27）：段落少时撑满宽度；段落多时每小节保持最小宽度（电脑 72px，手机 56px），超出部分往右滚。原生滚动条隐藏，换成编排区底部、时间线那一列下面的自定义滚动条 `#arrBar`（滑块可拖，点轨道跳一页，不需要滚动时隐藏，`updateBar()`）。Shift + 滚轮横向滚动；触控板横向滑动是原生行为。拖动段落、播放头把手到左右边缘 40px 内时自动滚动（`edgeScroll()`）。

**轨道**（`lanes()` 决定显示哪些，**没有内容的轨道不显示**）：

| 轨道 | 出现条件 | 颜色变量 | 可做的事 |
|---|---|---|---|
| 旋律（按乐器各一条：钢琴、弦乐……） | 某段有该乐器的旋律 | `--i-<乐器>` | 名称旁的 ▾ 换整条轨道的乐器；点片段选中 → 钢琴卷帘 |
| 军鼓 | 有军鼓（内部键 `clap`） | `--hits` | 点片段 → 鼓点格子 |
| 踩镲 | 有踩镲（内部键 `snap`） | `--hits` | 同上 |
| 和弦 | 已编曲 | `--chords` | 拖动互换、点击 → 和弦选择 |
| 贝斯 | 已编曲 | `--bass` | 只读，由和弦和风格生成 |
| 鼓 | 已编曲且风格有鼓（纯钢琴没有） | `--kit` | 只读 |

每条轨道右边的喇叭图标是静音开关（存在 `song.mute`），只影响播放和 WAV 导出，MIDI 总是导出全部轨道。

**段落条**（时间线顶部，`.sec`）：显示段落名和拖动手柄。

- **点击**（手机上轻点）：选中整段，下方编辑区显示该段的旋律（没有旋律就显示鼓点格子，再没有就显示和弦）。
- **换顺序**：电脑上按住段落名左边的六点手柄（`.grip`，可点区域约 20×32）直接拖；手机上长按 0.4 秒（期间移动不超过 5px，有振动就振一下）再拖。所有轨道一起移动，蓝色竖线标出插入位置。
- **平移**：电脑上按住段落条其他地方拖；手机上直接滑。（`.sec` 是 `touch-action: none`，平移由 `panner()` 自己实现。）


**和弦块**（`.chord`）：

- **点击**：选中并试听，编辑区切到和弦选择。
- **拖到另一个和弦块上**：两个小节的和弦互换，可以跨段落。拖动时原位置显示虚线框，目标块加黑框。

**播放头**（Figma 27）：竖线 `#arrPlayhead` 不接收指针，**按住竖线不能拖**。段落条里有一个把手 `#arrTag`（`.ph-tag`，14×18 尖朝下的五边形；可点区域电脑约 24×32、手机约 32×32）。拖把手：播放头跟着走，对齐到 1/4 拍，范围 0 到总拍数；把手旁浮出当前时间（如 `0:08`），松手消失；正在播放时先停，松手后从新位置继续；拖到左右边缘 40px 内时自动滚动。代码：`dragPlayhead()`、`movePlayhead()`。

**空白处单击**：把播放头移到该拍，取消选中。

**"＋段落"**（`.add-sec`）：紧跟在最后一段后面，点开添加段落弹窗（见 3.5）。未编曲时也能用。

**悬停插入段落**（Figma 28，**只在电脑上**：`(hover: hover) and (pointer: fine)`）：鼠标在时间线上离两个段落的分界线水平 10px 以内时，编排区卡片**上方**冒出蓝色加号 `#insPin`（26×34 水滴形，尖端碰到卡片上沿），时间线上出现一条 2px 蓝色竖线 `.ins-line`。点加号或竖线（段落条以下的 20px 宽区域 `.ins-hit`）→ `openAdd({ insertAt: i })`，新段落插在这里。拖动、拖播放头、弹窗打开时不显示。加号放在卡片外面（卡片 `overflow: hidden`），用 `getBoundingClientRect` 定位，滚动时更新；工具栏下边距因此是 24px。代码：`showInsert()`、`placeInsert()`、`hideInsert()`。手机上没有这个功能，只能在最后添加。

### 3.4 编辑区

未选中任何东西时，编排区正下方显示一行小字“点击段落来编辑”（`#editorHint`，Figma 27）。选中后换成编辑卡片 `#editor`，由 `renderEditor()` 根据 `sel.type` 决定显示哪种：

| 选中 | 标题 | 内容 | 代码 |
|---|---|---|---|
| 旋律片段 / 段落 | 旋律 · 主歌 + 乐器 ▾（只改这一段） | 钢琴卷帘 | `buildPianoRoll()`、`prDown()`、`drawPR()` |
| 军鼓 / 踩镲片段 | 节奏 · 主歌 | 两行 16 分音符格子（军鼓、踩镲），点一下加或删一个鼓点 | `buildHitGrid()` |
| 和弦块 | 和弦 · 主歌 第 3 小节 | 第一排：调内 7 个和弦（标级数）；第二排：七和弦、挂留和弦、借用和弦 | `buildChordPicker()`、`setChord()` |

**钢琴卷帘的标尺和播放头**（Figma 31）：顶部 26px 标尺写着段内小节号 1、2、3……；点标尺 = 播放头跳到那里。播放头竖线贯穿标尺和网格，把手在标尺里，和编排区的把手是**同一个播放头**（全局位置 = 段落起点 + 段内拍），只能在本段范围内拖；拖的时候编排区的播放头同步移动，编排区自动滚动到能看见它。播放头在这一段里就显示；播放时走出可见范围，卷帘自动横向滚动。代码：`drawRuler()`、`placePRHead()`。

**钢琴卷帘的操作**：

- 拖音符本体：同时改音高和位置（对齐到 16 分音符），拖动时出现提示"G4 → A4"，换音高时会试听。
- 拖音符右边缘 8px 内：改长短。
- 双击空白：在该处加一个 1 拍长的音。
- 选中音符后按 Delete 或 Backspace：删除。

**编辑区右上角工具**：复制（在后面插入这段的副本，**副本是独立的**）、删除（按选中类型：段落 → 删整段，至少保留一段；旋律 → 清空旋律；节奏 → 清空鼓点；和弦选中时不显示删除）、关闭。**这里不放撤回和重做按钮**（用户决定，见 DECISIONS）。

### 3.5 添加段落弹窗 `#addModal`（Figma 26；手机横屏 M4）

由 `openAdd(opts)` 打开。从末尾“＋段落”打开时新段落插在“尾声”之前（没有尾声就放最后）；从电脑上的蓝色加号（3.8）打开时 `opts.insertAt` = 那个位置。弹窗里**不选位置**。

- **段落**：主歌、副歌、桥段、尾声（保留，只用于显示）。
- **乐器**：6 种。
- **节拍**：节拍器圆按钮（`#addMetro`，默认打开）+ 速度（`#addBpmRow`，±5，40–240，默认等于歌的速度；节拍器关闭时隐藏）。**这个速度只是录音时的速度**：音符按拍存，加进歌里按歌的速度播放，`song.bpm` 不变。录音期间不能改。
- **录音区** `#addArea`：和录音页同样的画面，只是更小：上面音高线，中间两行鼓点，下面录音按钮、计时和伴奏开关。右上角是音名 `#addNote`，开节拍器时下面有 8 个小点 `#addBeats`。**不做全屏预备拍**：开节拍器时 8 个小点依次点亮（两小节），不开时 `#addNote` 显示蓝色 3、2、1，之后变成音名。
- **按键**：正在录音时空格 = 军鼓、Alt = 踩镲、回车 = 停止并分析、**Esc = 直接关掉弹窗并丢掉这段录音（不确认）**。
- **伴奏开关**：只在已编曲、节拍器打开时显示。录音期间按弹窗里的速度循环播放第一段的和弦、贝斯和底鼓。
- **手机**：竖屏时录音区下面是军鼓、踩镲两个大按钮；横屏时弹窗变成全屏面板（第一行标题 + 段落 + 乐器 + 节拍 + 关闭，中间“大按钮 | 录音区 | 大按钮”，底部取消和添加）。电脑上没有大按钮。
- **添加**：录完才能点。已编曲时会自动配和弦。添加后自动选中新段落。

### 3.6 Suno 弹窗 `#sunoModal`（Figma 6）

三步：

1. **音频**：选"原声哼唱"或"我们的编曲"，然后下载。
2. **风格提示词**：由 `Arrange.sunoPrompt()` 根据风格、乐器、速度、调生成英文提示词，旁边有复制按钮。
3. **打开 Suno**：链接到 `suno.com/create`。

Suno 没有公开 API，所以只能这样手动交接（见 DECISIONS）。

### 3.7 "编曲"过渡动画（Figma 17 → 18 → 19，说明卡在 18 下方）

点"编曲"后（`#arrangeBtn` 处理 → `commit(..., 'arrange')` → `renderArr('arrange')`）：

1. 按钮变成转圈加"编曲中"，持续约 1.7 秒，然后换成风格切换条。
2. 新段落（前奏、复制的主歌、尾声）从中间展开（`.sec.enter`），复制段的片段淡入（`.clip.enter`）。
3. 和弦、贝斯、鼓三条轨道依次滑入，每条间隔 120ms（`.lane-enter`，用 `--i` 控制先后）。
4. 一块盖住新轨道的白色遮罩从左往右揭开，前面有一条带光晕的蓝色扫描线（`.wipe` + `.sweep`，1.2 秒，延迟 0.45 秒开始）。

切换风格时（`renderArr('style')`）只做第 4 步，没有延迟。系统设置了"减少动态效果"时，所有动画都关闭。

## 4. 键盘

| 键 | 作用 |
|---|---|
| 空格 | 首页：开始录音；录音页：军鼓（见第 2 节）；作品页：播放 / 暂停（焦点在按钮或输入框上时不触发） |
| Alt | 录音页：踩镲 |
| 回车 | 录音页：停止并分析 |
| Ctrl/⌘ + Z | 撤回 |
| Ctrl/⌘ + Shift + Z，Ctrl/⌘ + Y | 重做 |
| Delete / Backspace | 删除钢琴卷帘里选中的音符 |
| Esc | 录音页：放弃确认（两下）；其他：依次关菜单 → 关弹窗 → 取消选中 |
