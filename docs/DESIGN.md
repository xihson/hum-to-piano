## 字体

- 中文和界面文字：Noto Sans SC（400 / 500）。
- 数字、音名、和弦名：Inter（500 / 600），并开启等宽数字 `font-variant-numeric: tabular-nums`。

两者都从 Google Fonts 加载，并配了系统字体作为后备。

## 尺寸

- 内容最大宽度 1200px，两侧留白 `clamp(16px, 4vw, 48px)`。
- 圆形按钮 44px，主录音按钮 132px（手机上 112px），停止按钮 80px。
- 首页三个圆形按钮的间距是 **9px**（用户亲手改的）。
- logo 距页面顶部 29px（等于原来单行 logo 的位置）。
- 编排区：轨道名列 150px（手机上 112px），段落条高 32px，轨道高 46px（3 条以内时 60px）；每小节宽度 40–110px，自动计算。

## 文案规则（用户定的）

1. **一看就懂的功能不加说明文字**。不要在按钮旁加小字解释它是干什么的，用图标或很短的标签就行。
2. 只有看不出来的地方才加提示，比如作品页空状态的"选中段落来编辑"。
3. 录音画面不标注"旋律 / 拍手 / 响指"，用户自己知道录了什么。
4. 界面语言目前是中文，以后要支持英语和德语，所以不要把文字画进图片或 SVG 里。
5. 错误提示要说清楚发生了什么、接下来怎么做，不道歉、不含糊。

## 图标

Lucide 风格：24×24，2px 描边，圆角端点。拍手（两只手 + 三条火花线）、响指（一只手 + 火花）、踩镲是自己画的。SVG 内容在 `app.js` 的 `ICONS` 里；Figma 的 `Components` 板上有同名组件。
