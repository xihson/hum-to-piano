# 哼唱成曲

哼一段旋律、拍手、打响指，转成钢琴旋律和鼓点，再一键编曲。所有处理都在浏览器里完成，录音不会上传到服务器。

- `/` — 第一版：哼唱转钢琴，导出 MIDI。
- `/v2/` — 第二版原型：一个录音按钮同时识别哼唱、拍手、响指；作品页可拖动和弦、段落和音符；一键编曲（6 种风格）；下载 MIDI / WAV / 原声；Suno 提示词。

## v2 代码结构

| 文件 | 内容 |
|---|---|
| `v2/js/theory.js` | 音名、调性识别、和弦、自动配和弦 |
| `v2/js/dsp.js` | 音高识别（YIN）、拍手/响指检测与分类、速度估计 |
| `v2/js/synth.js` | 合成音色、鼓、节拍器、WAV 导出 |
| `v2/js/arrange.js` | 编曲风格、歌曲编译成事件、MIDI 导出 |
| `v2/js/app.js` | 界面、录音、拖动交互、播放、撤回 |
| `v2/dev/fixture.js` | 开发用的合成录音（不随页面加载） |
